# 🔐 Password Generator

A modern and secure **Password Generator Web Application** built using **HTML, CSS, and JavaScript**.
This application helps users generate strong and random passwords to improve online security.
]

##  Features
*  Generate strong and secure passwords
*  Adjustable password length using slider
*  Option to include uppercase letters
*  Option to include lowercase letters
*  Option to include numbers
*  Option to include symbols
*  One-click copy password to clipboard
*  Clean and responsive UI

##  Learning Goals

This project helped me practice:

* JavaScript fundamentals
* DOM manipulation
* Event handling
* UI interaction
* Logic building
